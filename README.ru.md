# HOTskip-Image

**HunyuanImage-3.0 — самая большая открытая модель картинок (80B MoE) — на ноутбуке с видеокартой 8 ГБ.**

Tencent рекомендует **≥ 3 × 80 ГБ** видеопамяти (Instruct-версии — ≥ 8 × 80 ГБ).
HOTskip-Image запускает Instruct-Distil на **RTX 4070 Laptop (8 ГБ) + 32 ГБ ОЗУ**:

- пик видеопамяти **4,7 ГБ**;
- картинка 1024×1024, 8 шагов — **~78 секунд** (первая наивная версия — 200 с).

![лиса](assets/fox.png)

## Как это работает

За шаг диффузии через модель идёт ~4400 токенов, поэтому на каждом шаге нужны почти **все** эксперты:
все 40 ГБ весов экспертов проходят через видеокарту 8 раз на картинку. Задача — сделать этот поток дешёвым:

1. В видеокарте постоянно лежит только мелочь (~1 ГБ).
2. Внимание и общий MLP слоя копируются отдельным CUDA-потоком, пока считается предыдущий слой.
3. Эксперты читаются прямо из safetensors параллельными `pread` в закреплённые буферы на 3 слоя вперёд, потом одной копией в видеокарту; кэш ОС держит то, что влезает в ОЗУ.
4. VAE включается на видеокарте только в конце (fp16, по кускам).
5. TaylorCache (встроен в модель): часть шагов предсказывается, а не считается — такой шаг вообще не читает эксперты.

## Запуск

```bash
./setup.sh        # venv, официальный код Tencent, веса NF4 (~51 ГБ)
HY3_TAYLOR=2,1,2,1 .venv/bin/python hy3run.py "a red fox sitting in snow, photo" fox.png 8 1024x1024
```
